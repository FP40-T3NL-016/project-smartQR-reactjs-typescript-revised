SmartQR Data Analyzer - React TypeScript Tailwind Version

How to run:
1. Open this folder in VS Code.
2. Open Terminal.
3. Run: npm install
4. Run: npm run dev
5. Open the local URL shown by Vite, usually http://localhost:5173/

Build test:
npm run build
